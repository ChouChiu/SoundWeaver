# SoundWeaver

SoundWeaver 是一个多声道与杜比全景声（Dolby Atmos）制作工具，支持从 E-AC-3 JOC 提取多声道分轨与 ADM BWF 母带，并一键生成 Apple Music 风格动态歌词、完整播放器、滚动波形以及 3D 空间声场视频


## 快速上手

### 系统依赖
- **Python** 3.11+
- **FFmpeg**（需启用 `libvpx-vp9`；推荐支持 `h264_nvenc` / `hevc_nvenc` 硬件加速）
- **Bun** 或 **Node.js** 18+

### 安装与运行
```bash
# 1. 安装 Python 依赖
uv sync

# 2. 编译前端渲染器（首次运行前执行）
cd renderer && bun install && bun run build && cd ..

# 3. 启动应用
uv run soundweaver
```

> **提示**：首次生成视频时，程序会自动下载配套的 `chrome-headless-shell`（约 100 MB，保存在 `~/.cache/soundweaver/chrome`）


## 主要功能

### 杜比全景声与音频分轨
- **内置 E-AC-3 JOC 软解**：无需依赖杜比官方闭源套件，基于 ETSI TS 103 420 规范直接从码流重构空间音频对象（支持 5 声道下混的 JOC 码流，即流媒体常见的 5.1 核心）
- **12 种渲染布局**：从 2.0、5.1、7.1、5.1.4、7.1.4 到 9.1.6，按对象位置做恒功率房间声像，渲染到 2.0 / 5.1 / 7.1 时套用码流自带的 trim 修剪，并遵守对象的区域约束；ISF 对象按其环形布局定位，读取扩展精度位置，房间外的对象沿方向落到墙面
- **内置 AC-4 软解**：FFmpeg 只能读取 AC-4 容器，解码按 ETSI TS 103 190 自行实现（频谱解码、立体声与多声道矩阵、IMDCT 块切换、A-SPX、A-CPL），解码结果缓存为 FLAC 后供分轨、波形与播放器视频使用；Apple Music 的 AC-4 IMS 已与同曲 E-AC-3 版本对照验证，Dolby 测试码流的 2.0 与 5.1（含 A-SPX、A-CPL 与 29.97 fps 重采样）已与其 AAC 和 DD+ 参考对照验证；也支持裸 `.ac4` 码流；默认呈现带独立对象组时（如逐呈现设定对白电平的个性化码流），对白等对象按其 OAMD 渲染后混入声道床或并入 A-JOC 对象
- **AC-4 杜比全景声（A-JOC）**：对象由下混信号经 A-JOC 重建，元数据转换后交给 E-AC-3 全景声同一套渲染器，扬声器渲染、声场视频与 ADM BWF 导出均可用；已用真实母带验证，完整重建与核心下混的扬声器能量分布一致，同一首歌 15 对象与 20 对象两个版本的 7.1.4 渲染逐声道相关度 0.90 至 1.00、电平差 0.2 dB 以内；7.1.4 等沉浸式声道元素（声道模式 11 以上）暂不支持
- **常用分轨提取**：一键提取人声（中置）、伴奏（前置去人声）、环绕、顶置、低频（LFE）及高低频分音；立体声音源支持 Mid/Side 与人声伴奏分离
- **零相位分频**：高低频分轨各为 24 dB/oct、交越点 -6 dB，二者相加逐样本还原且互相无延迟
- **ADM BWF 母带导出**：默认导出 Dolby Atmos Master ADM Profile v1.1 格式，包含空间对象轨迹。勾选「移除静音声床占位」可将保留独立 LFE 的通用 ITU ADM 另存为 `*_adm_compact.wav`
- **相位校正与容错**：自动补偿 Ls/Rs 的 90° 编码相移；基于 Edit List 精准裁齐时间轴消除预热延迟；码流损坏时给出所在帧号

### 视频可视化生成
- **Apple Music 风格播放器视频**（`.mkv` / `.webm`）：
  - 完整还原本体界面（横屏左封面右歌词，竖屏自适应手机布局）
  - 支持 Mesh Gradient 流体渐变（可随 50–120 Hz 低频律动）、动态色块与透明背景
  - 包含逐帧 FFT 实时频谱、曲目信息、进度条及 Dolby Atmos 徽标
  - 自动过滤歌词首尾冗余的制作人员与版权声明
- **逐字动态歌词视频**（`.webm`）：单行居中动态字幕，Apple Music 逐字平滑高亮与淡入淡出，导出 VP9 带透明通道，可直接拖入剪辑轨道叠加
- **3D 空间声场可视化**（`.webm`）：在 3D 空间内实时展示全景声对象的三维位置、电平光晕与运动轨迹；支持按分轨联动暗化（直观展示各声道声音分布）
- **水平滚动波形**（`.mp4`）：双声道上下分轨滚动，中央固定播放头，左侧高亮、右侧暗化，经动态范围压缩强化波形细节
- **封面渐变背景**（`.png`）：基于 k-means 提取封面主色调并向下平滑压暗，用于视频背景底图

### 批量与专辑模式
- **歌词自动匹配**：批量导入时自动扫描同级及子目录下的 `.ttml` 歌词，智能清理音轨号与括号后缀后与歌曲元数据交叉比对
- **整张专辑无缝连播**：可将整张专辑渲染为一个连续的长视频，音频无损拼接，切歌时封面、歌词与背景流体平滑过渡
- **动态封面支持**：支持将无声循环视频（`.mp4` / `.mov` 等）作为 Apple Music 动态封面，自动抽帧并在各并行分段中时间轴精确循环


## 常用操作与快捷键

| 操作 | 方式 / 快捷键 | 说明 |
| :--- | :--- | :--- |
| **导入素材** | 直接拖拽 | 支持拖入音频（`.m4a`（含 AC-4）/ `.ac4` / `.eac3` / `.wav` 等）、封面图片、动态视频封面或 `.ttml` 歌词 |
| **开始任务** | `Ctrl + Enter` | 将勾选的产物加入队列并开始处理 |
| **中止任务** | `Esc` | 安全取消当前正在执行的任务 |
| **添加单曲** | `Ctrl + Shift + B` | 在批量页面添加单曲音频 |
| **导入专辑** | `Ctrl + Shift + M` | 导入整个专辑目录并自动开启专辑模式 |
| **打开产物** | 双击已完成任务 | 在任务与日志面板双击即可用系统默认程序打开对应输出文件 |


## 性能与渲染机制

- **播放器分段预读**：普通音频、360RA、Audio Vivid 和非对象 AC-4 先缓冲约半秒，后台预读约 6 秒，已解码片段保留在临时文件供跳转；Atmos 对象播放完成前置元数据准备后按 PCM 段交付
- **GPU Vulkan 硬件合成**：页面与 Three.js 场景通过 ANGLE Vulkan 强制启用显卡渲染，分段浏览器分时调度 GPU
- **确定性分段并行**：无头 Chromium 基于 CDP `BeginFrame` 确定性时钟切片并行渲染，渲染完毕后无损拼接，彻底消除接缝跳变；无歌词区间自动复用透明关键帧跳过空跑
- **快速截图加速**：不透明视频默认使用 JPEG（质量 90）帧流，截图耗时约为 PNG 的一半（720p 播放器片段 CRF 18 编码后 SSIM 0.997）
- **硬件编码自适应**：支持 H.264 NVENC / HEVC NVENC / libx264，超出硬件尺寸限制（H.264 最大 4K、HEVC 最大 8K）或无显卡时自动回退至软件编码
- **分块渲染防溢出**：视频单边最高支持 16384 px；3D 声场超过 8K 时自动开启分块渲染再拼接，避免触发 WebGL 显存上限
- **写入保护**：在目标目录内使用独立的临时目录写入产物，成功后原子替换目标，中断时保留已有文件

> **调试模式**：运行前加入环境变量 `SOUNDWEAVER_DEBUG=1 uv run soundweaver` 即可在终端输出浏览器切片耗时与 WebGL 详细诊断日志


## 项目结构与重构依据

- `features/` 按功能组织，`source`、`batch` 生成统一的 `Project`，`monitor` 管理播放列表与空间监视，`tasks` 管理任务列表、日志和 Qt 工作线程
- 各导出功能在自己的 `panel.py` 读取界面参数，由 `service.py` 构建和执行任务，通过 `features/registry.py` 注册，分轨功能先于依赖分轨的导出执行
- `core/planning.py` 提供单曲和批量共用的规划合约与路径检查，批量规划复用每轨的可用性检查，`core/runner.py` 负责执行顺序、并行与取消
- `core/playback_source.py` 负责源格式分派、准备 PCM 和对象元数据、管理临时文件，Qt 播放引擎负责设备输出、播放状态和电平信号
- `core/codecs/` 管理编解码器与原生进程边界，`renderer/src/` 按歌词、播放器、声场和实时监视组织，浏览器参数由 CLI 共用
- `ui/` 组合页面并提供共享的 Fluent 控件、颜色、间距和字体，素材页和监视页随窗口宽度重排，导航、输出开关、播放条支持键盘操作｜[Fluent 2 布局](https://fluent2.microsoft.design/layout) · [可访问性](https://fluent2.microsoft.design/accessibility)
- 对照 Spatial Audio Tools 0.8.0 的 Audio Vivid 集成说明、5.1.4 测试样本及本地 AVS3 Part 3 规范，验证声道顺序与采样一致性，现有 SoundWeaver 格式支持和导出选项以本项目为准
