# SoundWeaver

SoundWeaver 是一个多声道与杜比全景声（Dolby Atmos）制作工具。支持从 E-AC-3 JOC 提取多声道分轨与 ADM BWF 母带，并一键生成 Apple Music 风格动态歌词、完整播放器、滚动波形以及 3D 空间声场视频。


## 快速上手

### 系统依赖
- **Python** 3.11+
- **FFmpeg**（需启用 `libvpx-vp9`；推荐支持 `h264_nvenc` / `hevc_nvenc` 硬件加速）
- **Bun** 或 **Node.js** 18+

### 安装与运行
```bash
# 1. 安装 Python 依赖
uv sync

# 2. 编译前端渲染器（首次运行前执行）
cd renderer && bun install && bun run build && cd ..

# 3. 启动应用
uv run soundweaver
```

> **提示**：首次生成视频时，程序会自动下载配套的 `chrome-headless-shell`（约 100 MB，保存在 `~/.cache/dolbytool/chrome`）。


## 主要功能

### 杜比全景声与音频分轨
- **内置 E-AC-3 JOC 软解**：无需依赖杜比官方闭源套件，基于 ETSI TS 103 420 规范直接从码流重构空间音频对象。
- **12 种渲染布局**：支持下混重构至 2.0、5.1、7.1、5.1.4、7.1.4 到 9.1.6（遵循 ITU-R BS.2127 声像算法与 trim 元数据修剪规则）。
- **常用分轨提取**：一键提取人声（中置）、伴奏（前置去人声）、环绕、顶置、低频（LFE）及高低频分音；立体声音源支持 Mid/Side 与人声伴奏分离。
- **ADM BWF 母带导出**：导出符合 Dolby Atmos Master ADM Profile v1.1 规范的 BWF/RF64 文件，包含完整空间对象轨迹，可直接导入 DAW 或杜比全景声渲染器。
- **相位校正与容错**：自动补偿 Ls/Rs 及 Lb/Rb 的 90° 编码相移；基于 Edit List 精准裁齐时间轴消除预热延迟。

### 视频可视化生成
- **Apple Music 风格播放器视频**（`.mkv` / `.webm`）：
  - 完整还原本体界面（横屏左封面右歌词，竖屏自适应手机布局）。
  - 支持 Mesh Gradient 流体渐变（可随 50–120 Hz 低频律动）、动态色块与透明背景。
  - 包含逐帧 FFT 实时频谱、曲目信息、进度条及 Dolby Atmos 徽标。
  - 自动过滤歌词首尾冗余的制作人员与版权声明。
- **逐字动态歌词视频**（`.webm`）：单行居中动态字幕，Apple Music 逐字平滑高亮与淡入淡出，导出 VP9 带透明通道，可直接拖入剪辑轨道叠加。
- **3D 空间声场可视化**（`.webm`）：在 3D 空间内实时展示全景声对象的三维位置、电平光晕与运动轨迹；支持按分轨联动暗化（直观展示各声道声音分布）。
- **水平滚动波形**（`.mp4`）：双声道上下分轨滚动，中央固定播放头，左侧高亮、右侧暗化，经动态范围压缩强化波形细节。
- **封面渐变背景**（`.png`）：基于 k-means 提取封面主色调并向下平滑压暗，用于视频背景底图。

### 批量与专辑模式
- **歌词自动匹配**：批量导入时自动扫描同级及子目录下的 `.ttml` 歌词，智能清理音轨号与括号后缀后与歌曲元数据交叉比对。
- **整张专辑无缝连播**：可将整张专辑渲染为一个连续的长视频，音频无损拼接，切歌时封面、歌词与背景流体平滑过渡。
- **动态封面支持**：支持将无声循环视频（`.mp4` / `.mov` 等）作为 Apple Music 动态封面，自动抽帧并在各并行分段中时间轴精确循环。


## 常用操作与快捷键

| 操作 | 方式 / 快捷键 | 说明 |
| :--- | :--- | :--- |
| **导入素材** | 直接拖拽 | 支持拖入音频（`.m4a` / `.eac3` / `.wav` 等）、封面图片、动态视频封面或 `.ttml` 歌词 |
| **开始任务** | `Ctrl + Enter` | 将勾选的产物加入队列并开始处理 |
| **中止任务** | `Esc` | 安全取消当前正在执行的任务 |
| **添加单曲** | `Ctrl + Shift + B` | 在批量页面添加单曲音频 |
| **导入专辑** | `Ctrl + Shift + M` | 导入整个专辑目录并自动开启专辑模式 |
| **打开产物** | 双击已完成任务 | 在任务与日志面板双击即可用系统默认程序打开对应输出文件 |


## 性能与渲染机制

- **GPU Vulkan 硬件合成**：页面与 Three.js 场景通过 ANGLE Vulkan 强制启用显卡渲染，分段浏览器分时调度 GPU。
- **确定性分段并行**：无头 Chromium 基于 CDP `BeginFrame` 确定性时钟切片并行渲染，渲染完毕后无损拼接，彻底消除接缝跳变；无歌词区间自动复用透明关键帧跳过空跑。
- **快速截图加速**：不透明视频默认使用高质量 JPEG（质量 95）帧流流水线，相比 PNG 提取提速约 60%（SSIM 0.994）。
- **硬件编码自适应**：支持 H.264 NVENC / HEVC NVENC / libx264，超出硬件尺寸限制（H.264 最大 4K、HEVC 最大 8K）或无显卡时自动回退至软件编码。
- **分块渲染防溢出**：视频单边最高支持 16384 px；3D 声场超过 8K 时自动开启分块渲染再拼接，避免触发 WebGL 显存上限。
- **写入保护**：所有产物先写入临时文件（`.<文件名>.partial.<ext>`），完成后原子替换，中断不破坏已有文件。

> **调试模式**：运行前加入环境变量 `DOLBYTOOL_DEBUG=1 uv run soundweaver` 即可在终端输出浏览器切片耗时与 WebGL 详细诊断日志。
